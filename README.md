# AI Challenge2 — 한국어 장면 텍스트 VQA

간판·메뉴판 등의 **이미지, 질문, 보기 4개**를 받아 정답 `a/b/c/d`를 선택하는 프로젝트입니다. Qwen3-VL과 Gemma의 학습 여부·입력 설정이 다른 뷰를 결합해, 단독 정확도와 서로 다르게 틀리는 성질의 균형을 탐색했습니다.

원본 작성자는 **김상엽**입니다. 초기 발표에는 팀원 최재호·김상엽·이혜영·정진혁·최준혁이 기재되어 있습니다. 이 저장소는 제공 자료를 정리한 포트폴리오·복습 문서이며 개인별 담당 역할은 확인되지 않았습니다.

## 결과와 근거

| 단계 | 내부 validation | Public LB | 조건·출처 |
|---|---:|---:|---|
| 이전 최고 단일 Qwen 뷰 Q2 | 0.9667 | 확인 필요 | Qwen3-VL-8B LoRA, 1024 시각 토큰, TTA 1. 설명 노트북 셀 1 |
| 제공 노트북의 중간 7뷰·3계열 | 0.9733 | 0.97140 | Q·HR·G, VARCO 포함. 설명 노트북 셀 1·21 |
| 회고록·최종 발표의 7뷰·4계열 | **0.9767** | **0.97378** | Q·HR·G·GL, Gemma LoRA 추가 및 VARCO 제외. 회고록 도입·§2, 최종 발표 슬라이드 1·2 |

validation은 자료상 이미지 MD5 그룹 홀드아웃 약 600행입니다. Public LB는 별도 평가이며, 최종 발표 슬라이드 5는 Public 3,357행으로 기록합니다. 위 수치는 **원본에 보고된 결과**로, 이번 문서화 작업에서 재학습하거나 재측정하지 않았습니다. Q2는 이전 최고 단일 Qwen 뷰이지 전체 실험의 최고 단독 모델을 뜻하지 않습니다.

## 최종 접근

회고록·최종 발표의 구성은 `Q, Q2, Q3 / HR, HR2 / G26B / G26L`입니다. 뷰별 온도를 보정한 후 계열 내부 로그확률을 평균하고 네 계열에 각각 1/4을 줍니다. Q의 각 뷰는 1/12, HR의 각 뷰는 1/8, G26B·G26L은 각각 1/4입니다.

**제공 노트북은 이전 3계열 단계입니다.** G26L 학습·추론 코드와 최종 예측 배열은 포함되지 않아, 공개 노트북 실행만으로 최종 점수를 재현할 수 없습니다. [근거와 불일치](docs/sources.md)를 함께 읽어 주세요.

## 핵심 배움

- 정확한 뷰라도 기존 앙상블과 같은 문항을 틀리면 기여가 작습니다. 다양성과 정확도를 함께 봐야 했습니다.
- 특정 표기 유형에만 적용한 프롬프트가 도움이 됐습니다. 전체 문항에 영향을 주는 개입은 고침과 망침을 함께 비교해야 했습니다.
- 데이터 편향의 발견과 실제 점수 개선은 다릅니다. 반복 튜닝한 validation과 Public LB도 최종 독립 평가를 대신하지 못합니다.
