## 입력과 증거 수준

지시서 `VQA_CODEX_TASK.md`는 원하는 작업의 범위를 정하는 자료입니다. 실험 수치를 입증하는 자료로 사용하지 않았습니다. 지시서에 언급된 원본 ZIP은 이 대화에 첨부되지 않았습니다. 대신 GitHub `ho0829-ui/ai-challenge-2`의 커밋 `e422827f716ca0307189e85ed521ded1f44661b6`에서 같은 이름의 5개 파일을 읽었습니다. 원본 checkout의 파일은 보존했으며 새 문서·공개 복사본은 별도 폴더에 만들었습니다.

노트북 셀 번호는 **markdown 포함 전체 셀의 1부터 시작하는 위치**입니다. 코드 주석의 “1. 설치”, “14. 앙상블” 같은 섹션 번호와 다릅니다. 슬라이드는 `ppt/slides/slideN.xml`의 N을 기준으로 셉니다. 도형 안의 텍스트를 추출해 대조했고 별도 이미지 OCR을 실행한 것은 아닙니다. 두 PPTX에는 `ppt/media` 파일과 외부 링크 관계가 없었습니다.

증거를 다음처럼 구분했습니다.

- **코드 확인:** 실제 분할·순열 복원·학습 설정·결합 함수의 동작을 읽어 확인한 내용.
- **보고된 결과:** 노트북 markdown·주석, 회고록, 발표의 수치. 원시 예측이나 성능 로그로 재계산한 값이 아님.
- **작성자 해석:** 학습이 상관을 키운 이유, 출제 편향, 라벨 오류의 판정 등. 데이터가 없어 독립 확정하지 못한 설명.
- **일반 개념·향후 계획:** VQA/VLM, LoRA, calibration 설명과 재실험 제안. 해당 프로젝트가 이미 실행한 것으로 서술하지 않음.

## 공개용 정리 내역

모델·프롬프트·학습·TTA·calibration·예측 집계는 바꾸지 않았습니다. ZIP 경로·비밀번호·개인 실험 폴더는 `VQA_ZIP_PATH`, `VQA_ZIP_PASSWORD`, `VQA_EXP_DIR` 환경 설정으로 대체했습니다. 캐시의 사용자 절대 경로는 `HF_HOME` 또는 사용자 기본 캐시를 사용하도록 바꿨습니다. 비밀번호 값을 문서나 새 파일에 복사하지 않았습니다.

노트북의 widgets·Colab 런타임 metadata와 셀 metadata를 제거했고 셀 ID를 넣어 공개 파일의 형식을 정리했습니다. 원래 비어 있던 출력·실행 번호는 비어 있게 유지했습니다. 셀을 추가·삭제하거나 순서를 바꾸지 않았습니다. 공개 노트북도 도입 markdown의 **중간 성과 설명**을 보존하므로 README의 최종 결과와 다를 수 있습니다.

발표 파일에는 외부 링크와 삽입 미디어가 없으며 텍스트·문서 속성을 민감 패턴 점검 대상으로 확인했습니다. 원본 작성자와 발표자 이름은 출처 정보로 보존했습니다. 공개 권한 전체를 보장하는 법률 검토를 한 것은 아닙니다. 데이터·이미지·가중치는 패키지에 없습니다.
