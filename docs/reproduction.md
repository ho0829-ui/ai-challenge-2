# 재현 안내: 실행 가능한 단계와 확보해야 할 자료

## 재현 상태를 먼저 구분하기

이 저장소는 원본에 근거한 문서와 공개용 노트북을 제공합니다. **GPU 전체 학습·추론·대회 점수 재현은 미검증입니다.** 제공 코드의 대상은 중간 0.97140·3계열 구성입니다. 회고록·발표의 최종 0.97378·4계열에는 G26L 코드와 어댑터·예측이 추가로 필요합니다. 문서에 최종 가중치가 있다고 실행 구현이 완성된 것은 아닙니다.

이번 작업에서 노트북 형식·Python 구문·상대 링크·가중치 합을 검사했고, 원본 함수 일부를 추출해 CPU 커널에서 합성 데이터로 실행했습니다. 다수결의 채택·탈락, 온도 보정의 정규화, torch backward, safetensors 저장·읽기를 확인했습니다. 실제 데이터 accuracy 검증은 아닙니다. 원본 코드 셀의 출력은 모두 비어 있었고 실행 번호도 없었습니다. 위젯 메타데이터를 실행 증거로 사용하지 않았습니다.

## 1. 자료와 권한 확보

필수 데이터는 `train.csv`, `test.csv`, `sample_submission.csv`와 `path`에 지정된 이미지입니다. dev 추가 학습에는 `dev.csv`의 복수 라벨이 필요합니다. 대회 제공 경로에서 사용·배포 권한을 확인해 별도로 확보하세요. 원본 압축 파일·이미지는 이번 작업에 제공되지 않았으며 코드와 같은 디렉터리에 있다고 가정하지 않습니다.

모델은 Qwen8B·4B, Gemma26B-A4B, 중간 구성의 VARCO14B입니다. 모델별 다운로드 권한·라이선스·필요 시 승인된 계정 접근을 확인해야 합니다. 이 작업에서는 가중치를 다운로드하지 않았고 gated 여부·토큰의 유효성을 시험하지 않았습니다. 토큰과 데이터 압축 비밀번호는 채팅·저장소·로그에 넣지 말고 런타임의 비밀 설정으로 공급하세요.

## 2. 환경과 버전

원본 코드는 Colab의 `google.colab.drive`·`files`와 bf16 가능한 CUDA GPU를 전제로 합니다. 로더는 `device_map={"":0}`, bf16, SDPA를 사용합니다. CPU 환경에 그대로 전체 셀을 실행할 수 없습니다. 일반 Jupyter로 옮기는 Drive 연동 수정은 이 공개용 복사본에서 수행하지 않았습니다.

| 항목 | 원본에서 확인된 범위 | 이번 CPU 작업 |
|---|---|---|
| Python | metadata에는 이름만 있음; 실제 버전 확인 필요 | 3.12.14 |
| torch | 실제 버전 확인 필요 | 2.14.1+cpu |
| transformers | Qwen 설치 요구 `>=4.57.3`, 그 외 `>=5.17`; 실제 버전 아님 | 5.17.0 |
| peft | Qwen 설치 요구 `>=0.14`; 실제 버전 확인 필요 | 0.21.2 |
| accelerate / pyzipper | 버전 없는 설치 선언 | 1.15.0 / 0.4.0 |
| numpy / pandas / scipy | 실제 버전 확인 필요 | 2.5.3 / 3.0.6 / 1.18.1 |
| nbformat / nbclient / ipykernel | 원본 실행 환경 확인 필요 | 5.11.1 / 0.11.0 / 7.4.0 |

이번 CPU 조합은 **문서화·일부 함수 점검에 검증된 환경**이며 원본 GPU 실행 환경을 복원한 버전 목록이 아닙니다. 근거 없는 `requirements.txt`를 만들지 않았습니다. 초기 발표의 RTX 5060 Ti 16GB→Colab96GB와 notebook Colab 메타데이터만으로 정확한 GPU·CUDA 조합을 확정하지 않습니다.

근거: 코드 전용 셀 2·7·12·15; 초기 발표 슬라이드 5; 원본 metadata.

## 3. 공개용 경로·비밀번호 설정

공개 복사본은 모델과 예측 로직을 유지하고 다음 설정만 바꿨습니다.

| 변수 | 설정 방법·기본값 |
|---|---|
| `VQA_ZIP_PATH` | 데이터 ZIP의 경로. 기본 `/content/drive/MyDrive/VQA_INPUT/dataset.zip` |
| `VQA_ZIP_PASSWORD` | 비밀 런타임 값. 코드에 실제 비밀번호를 남기지 않음 |
| `VQA_EXP_DIR` | 어댑터·뷰 확률·결과를 보관할 폴더. 기본 `/content/drive/MyDrive/VQA_OUTPUT` |
| `HF_HOME` | 선택적 Hugging Face 캐시 경로; 미설정 시 사용자 캐시 |

파일 이름 자체에 모델이나 예측 의미가 있는 경로는 변경하지 않았습니다. `DATA_BASE`·`CACHE_DIR`의 Colab 로컬 작업 경로는 설정 셀에서 환경에 맞게 확인하세요. 데이터 압축 해제는 ZIP SHA256 기반 폴더와 완료 마커를 사용하며 절대 경로·`..` 항목을 거부합니다. MD5 분할과 다른 목적의 해시입니다.

코드 전용 셀 2 기본 `PHASE="internvl"`은 원본 그대로입니다. InternVL 실행 섹션은 실제로 없으므로 그대로 전체 실행하지 말고 시작할 때 **`PHASE="qwen"`을 선택**해야 합니다. 위젯 메타데이터·셀 실행 번호·출력은 공개용 정리 과정에서 제거했습니다. 삭제한 내용을 새 성능 출력으로 채우지 않았습니다.

## 4. 중간 3계열 노트북 실행 순서

아래는 **코드 전용 공개 노트북**의 실제 전체 셀 위치입니다. 설명 노트북에는 markdown이 추가돼 위치가 다릅니다. [셀 대응표](sources.md)를 참고하세요. 원본 주석의 “1~4번” 등은 코드 섹션 번호이며 전체 셀 위치와 다릅니다.

1. `PHASE="qwen"`, `RUN="Q"`를 설정합니다. 셀 2 설치 후 필요한 경우 세션을 재시작하고 셀 3~5의 Drive·경로·설정·데이터 분할을 실행합니다. seed42, 목표600, dev 기준을 모든 뷰에서 유지합니다.
2. 셀 7~9로 Qwen8B·LoRA와 학습을 준비합니다. `RESUME=True`이면 해당 폴더의 기존 어댑터를 읽어 학습을 건너뜁니다. 데이터·모델 revision·분할이 같은지 별도로 확인합니다. 셀 10으로 Q 뷰를 생성하고, 셀 11을 1024/Q2와 1280/Q3로 각각 실행합니다.
3. Qwen을 정리한 뒤 `RUN="HR"` 설정으로 공통 설정·분할과 셀 7~10을 실행합니다. 셀 11은 `VIEW_TAG="HR2"`, 토큰1024로 실행합니다. 바뀐 CFG·TTA가 의도와 맞는지 확인합니다.
4. `PHASE="gemma"`로 설치 요구를 확인한 뒤 같은 공통 데이터·validation을 준비합니다. 셀 12~13으로 G26을 만들고 셀 14로 표기 대상만 재채점한 G26B를 만듭니다. 모델 접근과 실제 프로세서 토큰 설정을 확인합니다.
5. `PHASE="varco"`로 공통 단계를 준비하고 셀 15에서 VC를 생성합니다. 기본은 `VC_MODE="A"`, `VC_TAG="VC"`, tile2, TTA1, batch8입니다. probe를 실행하면 결과 파일과 채택 설정을 구분합니다.
6. 공통 데이터 객체·`acc_of`·`write_sub`를 준비한 상태에서 셀 16을 실행합니다. Q/Q2/Q3/HR/HR2/VC/G26B 각각의 validation·test 확률과 `val_y.npy`가 모두 있어야 합니다. 기존 `.npy`가 있어도 공통 데이터 초기화를 생략할 수는 없습니다.
7. `sub_best.csv`를 확인하고 필요하면 셀 17의 Colab 내려받기를 사용합니다. ID 누락이 없고 sample submission과 순서·열 이름이 맞는지 검사하세요. 실제 대회 제출·점수 조회는 이 작업에서 수행하지 않았습니다.

셀 6의 정리 함수는 필요할 때만 실행합니다. `drop_models`는 캐시 삭제 기능이므로 단순히 readiness 확인용으로 호출하지 마세요. 학습/추론 재개 파일은 새 어댑터·입력 예산·데이터 행 순서와 호환되는지 확인해야 합니다. 원본 함수의 shape·ID 검증만으로 모든 재개 호환성이 보장되지는 않습니다.

## 5. 예상 산출물

| 산출물 | 의미 |
|---|---|
| `val_y.npy` | 내부 validation 정답 배열 |

최종 G26L 어댑터·확률 생성 방법은 제공 자료에 구현이 없습니다. 문서상의 4계열을 그대로 재현하려면 최종 코드와 온도·행 ID·예측 배열을 추가 확보해야 합니다. 현재 공개 노트북을 임의로 바꿔 최종 실험으로 포장하지 않았습니다.

## 6. 완료한 검증과 남은 확인

공개 파일은 JSON·스키마·구문·설정 변경 범위·상대 링크·파일 해시 대응을 점검했습니다. 원본 참고용 회고록과 발표 파일은 바이트 그대로 복사했습니다. 노트북의 core 코드·TTA·온도 함수는 변경하지 않았습니다.

실제 이미지 판독, 학습 체크포인트, G26L, 모델 다운로드, 전체 제출 파일의 정합성, 보고 accuracy·LB 재측정은 수행하지 않았습니다. 데이터·권한·GPU·최종 코드가 확보되면 해당 항목부터 검증해야 합니다. 데이터 수량·초기 실험의 다른 수치·개인 역할·배포 권한도 [확인 목록](sources.md)에 남겼습니다.
