# 07. 남은 오답의 성격과 좁은 개입

## 원본 수동 검토 기록

회고록 §3과 설명 노트북 셀 23은 작성자가 사진을 직접 보며 다음처럼 분류했다고 기록합니다. 이번 입력에는 그 사진과 문항별 예측이 없으므로 아래 분류를 **독립 확인한 라벨 판정**으로 사용하지 않습니다.

| 원본 분류 | 개수 | 기록된 사례·판단 | 현재 확인 수준 |
|---|---:|---|---|
| 검증 불가 | 5 | 개수 세기·부정형 등 사진만으로 판정 곤란 | 작성자 기록 |
| 모델 판독 실패 | 4 | 메뉴 줄과 가격 연결, 지도 구간 거리 등 | 작성자 기록 |
| 표기 변형 | 3 | 쌀의 날 / 쌀의 날 기념 등 | 작성자 기록, 처리 코드는 있음 |
| 문제 설계 모호 | 3 | 비상벨 사진에 112와 119 동시 표기 | 작성자 기록 |
| 라벨 오류로 분류 | 2 | `太阳镜`·`太阳帽`를 물었는데 정답이 치마(`民族裙`) | 원본 이미지·공식 라벨 재검토 필요 |
| **합계** | **17** | 분류 시점의 오답 집합 | 최종 14개와 동일 집합 여부 미확인 |

회고록은 후속에 오답 16 → 14가 됐다고 쓰고 최종 발표 슬라이드 5는 600행에서 최종 14개를 기록합니다. **17개 분류표를 최종 14개 분류처럼 제시하지 않습니다.** 자료만으로 어떤 3개가 달라졌는지 매핑할 수 없습니다. 표 합계·분모·예측 버전이 함께 있어야 시점별 비교가 가능합니다.

## 판독 실패, 모호성, 라벨 의심을 구분하기

판독 실패는 이미지 안에서 답이 비교적 명확하지만 모델이 읽거나 연결하지 못한 경우입니다. 이때 입력 처리·질문 방식·모델 개선의 목표를 세울 수 있습니다. 문항 모호성은 여러 해석 또는 보기가 허용되는 상황이어서 큰 모델로도 하나의 정답을 강제하기 어렵습니다. 라벨 의심은 자료의 정답과 시각 근거가 충돌한다는 주장으로, 원본·채점 규칙·가능한 다른 해석을 검토해야 합니다.

“검증 불가”도 실제로 문제가 틀렸다는 결론은 아닙니다. 작성자의 수동 판단 범주입니다. 오답 원인을 분리하면 어떤 오류에 계산 자원을 쓸지와 어떤 항목에 데이터 검토가 필요한지 구분하기 쉽습니다. 모든 남은 오답이 모델 크기와 무관하다는 보편 주장까지는 할 수 없습니다.

## 표기 변형에서 개입 폭을 좁혔다

코드 전용 셀 14는 보기를 공백 없이 소문자로 정규화하고 길이 2 이상인 보기의 부분문자열 포함 관계로 후보를 찾습니다. “같은 뜻”을 실제로 검사하지 않으므로 짧은 일반 단어가 우연히 포함된 경우도 잡힐 수 있습니다. 탐지 정확도나 false positive 비율은 자료에 없습니다.

대상에만 “사진에 적힌 글자와 완전히 일치하는 것을 고르라”는 지시를 넣고, 나머지 G26 확률은 유지합니다. 변형 validation 37행에서 0.8649 → 0.9189, test 대상 342행으로 기록됩니다. 최종 중간 앙상블 답 6행 변화와 LB +0.0004는 설명 노트북 셀 14와 최종 발표 슬라이드 7의 보고입니다. G26 자체 변경 행 수와 혼동하지 않습니다.

학습 Qwen에 같은 지시를 적용한 비교는 고침 0·망침 0이라고 부록에 남아 있습니다. 작성자는 LoRA의 프롬프트 고정으로 해석하지만 그 메커니즘을 별도 실험으로 증명한 것은 아닙니다.

## 작은 구간에서의 개선을 어떻게 읽는가

전후 정오답 표를 만들면 `고침 = 이전 오답·이후 정답`, `망침 = 이전 정답·이후 오답`, `순증 = 고침−망침`입니다. 전체 accuracy가 같아도 고침과 망침이 동시에 많으면 행동은 크게 바뀐 것입니다. 반대로 높은 단독 점수가 최종 답을 바꾸지 않을 수도 있습니다.

37행에서 선택한 프롬프트나 받아쓰기 개입을 수백·수천 행으로 확장할 때는 불확실성이 큽니다. 부록의 받아쓰기 사례는 validation +2(p=0.5)와 LB 감소가 함께 기록돼 있습니다. 신뢰구간·paired 평가·추가 holdout을 확보할 필요가 있습니다. 검정 한 번의 작은 p값도 반복 선택의 위험을 제거하지 않습니다.

근거: 코드 전용 셀 16의 `binomtest(r,r+g,0.5)`, 설명 셀 23, 최종 발표 슬라이드 5·6. 전체 수동 분석에 동일 검정이 적용됐는지는 확인 필요입니다.
