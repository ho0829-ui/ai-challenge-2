# 06. 실험을 가설과 판단으로 복습하기

수치는 원본의 보고값입니다. 원시 예측·로그가 없으므로 이번 작업에서 독립 재측정하지 않았습니다. 실험 날짜나 상세 순서가 없는 항목은 주제별로 묶었습니다. 비교 조건을 갖춘 표는 [results/experiments.md](../results/experiments.md)에 있습니다.

## 1. 무학습 Gemma 추가

**가설:** 학습한 Qwen 뷰와 다른 오류를 가진 모델이 앙상블의 남은 오답을 보완할 수 있다.

**설정:** Gemma 4 26B-A4B를 학습하지 않고 560 soft token, 보기 순서 TTA 2로 채점했다. 제공 코드에는 `google/gemma-4-26B-A4B-it` 모델 ID가 있다. 단독 G26과 표기 유형을 바꾼 G26B는 구분한다.

**결과:** 설명 노트북의 중간 단계는 Qwen 5뷰 LB 0.965 → G26 추가 0.970, +0.005를 기록한다. G26 단독 validation은 0.9550이고, G26B는 0.9583이다.

**해석:** 작성자는 다른 모델 구조와 학습 데이터가 만드는 다양성의 기여로 해석한다. 모델·지분·확신이 함께 달라져 구조 차이만의 효과를 인과적으로 분리한 것은 아니다.

**배운 점:** 단독 최고점만 보는 후보 선택으로는 유용한 보완 뷰를 놓칠 수 있다. 기존 오답을 실제로 고치는지 확인한다.

근거: 설명 노트북 셀 1·14, 코드 전용 셀 12·13, 회고록 §1.

## 2. 표기 변형 문항에만 프롬프트 변경

**가설:** 뜻이 비슷한 보기에서 의미보다 사진의 정확한 글자 일치를 강조하면 개선된다.

**설정:** 공백 제거·소문자 정규화 후 길이 2 이상인 보기가 다른 보기의 부분문자열인지 검사한다. 의미 동등성을 직접 판정하는 알고리즘은 아니다. G26 확률을 복사하고 대상 행만 새 지시로 다시 채점해 G26B를 만든다. Qwen 학습 뷰의 예측은 변경하지 않는다.

**결과:** 변형 validation 37행의 단독 정확도 0.8649 → 0.9189, 중간 앙상블 validation 0.9717 → 0.9733, LB 0.97100 → 0.97140. test 6,714행 중 대상은 342행이고 최종 앙상블 답 6행 변경으로 설명된다. 대상 행 수, Gemma 자체 예측 변경 수, 최종 앙상블 변경 수는 다른 지표다.

**해석:** 좁은 유형만 바꾸어 다른 구간의 영향을 제한한 사례다. 자료상 개선이지만 37행에서 선택한 프롬프트의 일반화는 별도 평가가 필요하다.

**배운 점:** “이해를 잘해라”보다 오류가 생기는 구체적 판단 기준을 찾아 개입하는 것이 유효했다.

근거: 코드 전용 셀 14, 설명 셀 14·17, 최종 발표 슬라이드 7.

## 3. 받아쓰기 결과 이식은 왜 제외했나

**가설:** OCR처럼 글자를 받아쓴 후 보기에 문자열 매칭하면 표기 오류를 더 줄인다.

**설정:** 표기 변형 구간의 받아쓰기·문자열 매칭을 기존 결과에 이식한 실험이다. 전체 구현은 제공되지 않고 부록에 결과가 남아 있다.

**결과:** validation +2문항, paired 검정 보고 p=0.5였지만 LB 0.97140 → 0.97080으로 감소했다. 부록은 test 342행 중 11행 변경과 순증 −4를 기록한다. 해당 순증의 평가 대상·정답 접근은 원시 로그 없이 독립 확인하지 못했다.

**해석:** 작은 subset에서 좋아 보이는 변화가 다른 평가에서 도움이 되지 않을 수 있다. p=0.5는 정확히 “실험이 실패할 확률 50%”라는 뜻이 아니다. 선택된 문항의 paired 변화가 영가설과 얼마나 양립하는지에 관한 값이며 표본이 작고 반복 시도하면 해석이 더 제한된다.

**배운 점:** 좋은 validation 관찰만 선택해 이야기하지 않고, 반대 평가 결과도 함께 남긴다.

근거: 설명 노트북 셀 23, 최종 발표 슬라이드 6.

## 4. Gemma LoRA와 VARCO LoRA는 다른 결과를 냈다

**가설:** 학습한 비-Qwen 뷰를 추가하면 정확도와 다양성의 균형이 좋아질 수 있다.

**설정:** Gemma 26B-A4B 학습 전후와 VARCO 14B 학습 전후를 각각 비교했다는 기록이다. Gemma 1 epoch, r32 설정은 최종 발표에 있지만 해당 셀·어댑터는 없다.

**결과:** Gemma 단독 0.9583 → 0.9650, Qwen 5뷰와 겹침 +0.051. Gemma LoRA 추가·VARCO 제외를 포함한 최종 변경은 LB +0.0024. VARCO는 단독 0.8967 → 0.9150, 겹침 +0.085, 앙상블 −2문항.

**해석:** 두 모델에서 학습 후 겹침 증가가 관찰됐으나 앙상블 기여는 달랐다. “정확도가 앙상블 수준에 근접할 때 학습이 남는 장사”라는 회고는 이 사례의 경험적 해석이다. 임계값을 증명한 규칙은 아니다. 특히 최종 LB의 +0.0024는 학습 단독 효과가 아니다.

**배운 점:** 뷰의 정답률·겹침·변경된 가중치와 복합 변경을 함께 기록한다.

근거: 회고록 §1·2, 최종 발표 슬라이드 2·3·4·6.

## 5. 더 큰 모델과 더 큰 입력이 포화에서 막혔다

**가설:** 모델 용량·입력 예산을 더 늘리면 판독 실패를 해결한다.

**설정:** InternVL3-38B 추가, Gemma 31B 추가·캐스케이드, 시각 입력 2048/3072, 타일링·크롭, 학습 Gemma 1120 토큰 추론 등이 기록된다. 실험별 전체 프롬프트·가중치는 제공되지 않는다.

**결과:** InternVL3-38B 단독 0.9367, 중간 5구성 모두 음수. 회고록의 후속 Gemma 31B 단독 0.9767은 최종 앙상블보다 높다는 뜻이 아니라 수치가 같은 별도 단독 실험이며, 7구성 앙상블 순증 0. 설명 노트북의 이전 Gemma 31B 캐스케이드 순변화 +2와 후속 투입 순증 0은 서로 다른 단계·설정이다. 학습 Gemma 1120은 단독 0.9667인데 앙상블 예측 변화가 0행으로 기록된다.

**해석:** 이미 맞히는 문항을 더 자신 있게 맞히는 것과 남은 앙상블 오답을 해결하는 것은 다르다. 이미지가 0.7~1.1MP여서 더 큰 입력의 이득이 없었다는 원본 해석도 실제 이미지가 없어 재확인하지 못했다.

**배운 점:** 단독 최고 성능 갱신을 채택의 충분조건으로 쓰지 않는다. 계산비용 증가 전에 해결하려는 오류의 유형을 확인한다.

근거: 회고록 §3, 설명 노트북 셀 23, 최종 발표 슬라이드 8.

## 6. TTA 확대·가중치 탐색·학습 연장은 자동 개선이 아니다

**가설:** 더 많은 순열, 더 정교한 가중치, 더 긴 학습이면 안정적으로 좋아진다.

**설정:** 부록은 순열 민감도 비교, 가중치 무작위 탐색, top-2 rerank를 기록하고 최종 발표는 375 가중치 조합, 저마진 25조합을 설명한다. 회고록은 Gemma LoRA 2 epoch를 추가 실험한다.

**결과:** 부록의 TTA2 비교는 0.9650으로 s=0 단독 0.9667보다 낮았다. 가중치 무작위 탐색은 LB 0.7050으로 기록되지만 해당 원인이 구현 문제인지 과적합인지는 로그 없이 확정하지 못한다. 발표의 375조합 최대 순증 +1은 이 무작위 탐색과 같은 실험인지 확인되지 않았다. Gemma LoRA 2 epoch는 단독 0.9683인데 앙상블 −4문항, LB −0.0012다.

**해석:** 더 복잡한 방법이 개선되려면 새로운 정보나 더 나은 판단을 실제로 추가해야 한다. 낮은 결과를 모두 하나의 이유로 설명하지 않는다.

**배운 점:** 바꾸기 전·후 같은 문항의 정오답을 비교하고, 실험 ID와 예측 배열을 남겨 나중에 실패 원인을 구분한다.

근거: 설명 노트북 셀 23, 회고록 §3, 최종 발표 슬라이드 8.
